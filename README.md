# Iran-License-Plate-City-Finder-iOS-Shortcut
An iOS Shortcut that identifies the city and county associated with Iranian vehicle license plates. Simply enter a license plate number to quickly find the corresponding location. Fast, simple, and easy to use directly from the Apple Shortcuts app.

⚡ Fast and lightweight  

📱 Designed for iPhone and iPad  

🔢 Supports Persian and English numbers  

🔒 Works locally using the included JSON database

📋 Requirements:

* iPhone or iPad
* Apple Shortcuts app
* Apple Files app
* The provided .shortcut file
* The provided .json database file

## 🚀 Installation

1. Add the JSON Database

First, download the .json file from this repository.

Then:

1. Open the Files app on your iPhone or iPad.
2. Go to On My iPhone or iPad.
3. Create a folder named:

" <strong>Plate shortcut</strong> "

4. Move or copy the downloaded .json file into the Plate Shortcut folder.

The final file path should look like this:

On My iPhone/Plate shortcut/Iran_license_plates.json

⚠️ Important: The JSON file must be placed inside the Plate Shortcut folder on On My iPhone. Do not move or rename the file after installation unless you also update the file path in the Shortcut.

2. Add the Shortcut

Download the provided .shortcut file from this repository and open it on your iPhone or iPad.

Tap Add Shortcut to add it to the Apple Shortcuts app.

If iOS asks for permission to access files, allow the required permissions.

▶️ Usage

Run the Shortcut and enter an Iranian vehicle license plate number.

The Shortcut reads the JSON database from:

On My iPhone/Plate shortcut/

and returns the corresponding city and county.

📁 Required File Structure

Make sure your Files app has the following structure:

    └── On My iPhone/iPad

     └── Plate shortcut
    
      └── Iran_license_plates.json

The Shortcut should also be installed in the Shortcuts app.

⚠️ Important

The JSON database is required for the Shortcut to work correctly.

If the Shortcut cannot find the database, check that:

* The Plate Shortcut folder exists under On My iPhone.
* The JSON file is inside that folder.
* The JSON filename has not been changed.
* The Shortcut has permission to access the file.

Enjoy!


## 🔒 Privacy

The Shortcut uses the included JSON database stored locally on your device.

It does not require an external API or online lookup service.

The license plate information entered into the Shortcut is used for the local lookup.

No account or external service is required to use the database
